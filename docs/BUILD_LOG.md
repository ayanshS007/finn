- Reachability: from this sandbox `curl` returned 000 for nseindia.com only because curl negotiates HTTP/2 and NSE's edge resets that stream through the proxy. Over HTTP/1.1 with a browser User-Agent everything works, so the client pins HTTP/1.1. `GET https://www.nseindia.com/` itself still returns 403 (Akamai) from here; content pages such as `/companies-listing/corporate-filings-announcements` return 200, and the API answers even without cookies. Warm-up therefore tries the home page and falls back to a content page, and tolerates failure (the API call decides if we are blocked). Yahoo `query1` returns 429 to curl but `yfinance` works.
- NSE endpoint verification (all live, 2026-10-29):
  - `/api/corporate-announcements?index=equities&symbol&from_date&to_date` works as specified (symbol optional; all-market day = ~700 rows). Fields: `an_dt`, `desc` (category), `attchmntText`, `attchmntFile`, `seq_id`, `hasXbrl`, `sm_name`, `symbol`.
  - `/api/results-comparision?symbol=` works but is **frozen at the Dec 2024 quarter** (INFY and HDFCBANK both end 31-Dec-2024; values are in Rs lakh). Returned as is; `results_comparison_period_end()` exposes the staleness.
  - `/api/corporates-financial-results?index=equities&period=Quarterly&symbol=` works but is **also frozen at Dec 2024** (INFY 144 rows, HDFCBANK 103 incl. both bases). Date filters return nothing newer; the unfiltered call returns only the Dec 2024 quarter for all 3,816 companies.
  - Found in the page JS (`dist/js/sections/corporate-filings.js`): since SEBI's integrated filing, newer results are served by **`/api/integrated-filing-results?index=equities&symbol=X&period_ended=all&type=Integrated Filing- Financials`** (`{data,size,page,totalCount}`; rows have `qe_Date`, `consolidated`, `audited`, `broadcast_Date`, `xbrl`, `ixbrl`, `seq_Id`; `pdf_attach` is the literal `.../corporate/null`). INFY has 14 rows, Mar 2025 to Sep 2026. `financial_results()` therefore merges legacy rows (to Dec 2024) with integrated rows (Mar 2025 on), newest first, each with `source`, `period_end`, `basis`, `is_bank`, `xbrl_url`, `ixbrl_url`, `attachment_url` and the raw row. The integrated XBRL/iXBRL files are the numbers source for S2 (iXBRL HTML fetched fine, 740 KB for INFY).
- NSE RSS: feed list is on `/static/rss-feed`; announcements feed is `https://nsearchives.nseindia.com/content/RSS/Online_announcements.xml` (also `Financial_Results.xml`, `Integrated_Filing_Financials.xml`, `Board_Meetings.xml` etc.). Items have company name, attachment link, text, pubDate and no symbol or id, and the feed repeats some items verbatim. The symbol is filled only on an exact match (caller's name map, or the attachment file-name prefix when it is a known symbol); otherwise None. pubDate comes in two formats (`dd-Mon-yyyy HH:MM:SS` and `DD-MON-YYYY HH:MM`).
- BSE (`bse` package 3.3.4): `getScripCode`, `announcements(scripcode=...)` paged by `Table1.ROWCNT`; works live. Attachment URL uses `AnnPdfOpen.aspx?Pname=` (same as screener).
- Prices: `yf.download(..., period="120d")` returns 120 trading sessions, not calendar days. `Close` is split-adjusted, not dividend-adjusted (`auto_adjust=False`).
- Screener: anonymous requests return all five tables and the documents section (annual reports, concalls with transcript/PPT/REC links). Units are noted per table (`Rs. Crores`; ratios have none). Bank pages use different row labels (Revenue, Financing Profit, ...). Document links missing for a company are reported in `warnings`, never guessed.
- Decisions: one normalised announcement dict for NSE, RSS and BSE (`exchange, symbol, company, category, subcategory, text, attachment_url, published_at (IST ISO), source_id, has_xbrl`); raw payloads stay in fixtures. Cache stores only HTTP 200. `ttl=0` means no cache read or write.
